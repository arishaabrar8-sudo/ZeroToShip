# DoomFolder

## Overview
DoomFolder is a C++17 command-line application that analyzes storage usage by recursively scanning folders. It categorizes files, displays storage statistics, sorts results, and provides warnings about large files.

## Features
- Recursive folder scanning
- Object-Oriented Programming (OOP)
- File categorization
- Storage dashboard
- Sorting by file name
- Sorting by file size
- Warning system for large files
- Command-line interface

## Technologies Used
- C++17
- STL
- std::filesystem
- Object-Oriented Programming
